# 波形叠影台：示波器分段、触发抖动与测量窗口谱系

信号完整性团队的分段捕获（segmented acquisition）审阅工具。导入分段原采样、时基、竖直
增益、探头衰减、触发时标、通道 deskew 与版本化测量区间；对齐重复事件、审查触发抖动与
测量分布；所有来源、解释、规则版本与人工裁定分开保存、可分支、可撤销、可回放到任意旧
事件。

## 安装（仅这一步）

```
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
```

## 验收与启动（仅这一条）

```
.venv/bin/python -m pytest -q; .venv/bin/uvicorn app:app --host 127.0.0.1 --port 5361
```

打开 http://127.0.0.1:5361 ：

1. 载入仓库内离线案例包（固定案例，非通用表格）；
2. 在「叠影 / 抖动分布 / 触发候选 / 测量窗 / 排除原因」五个视图中核对；
3. 对多峰段切换候选并接受（生成裁定事件，可撤销）；
4. 依次执行修订脚本：参数修订、局部源数据改动、互相冲突的人工决定（后提交者看到 409
   与双方差异）；
5. 导出数据库、删除本地库、重新导入，再回到任意旧事件，检查身份、顺序与来源关系。

## 领域规则（机器可读，见 `wavejit/rules.py` 与基础事件 `judgment.basis`）

- `R-TIME-0001`：时间轴不等间隔时一律用时间值相减/定位，禁止索引相减。
- `R-INTERP-0001`：缺样与饱和区间不进入插值（折线断开），也不进入测量统计。
- `R-ALIGN-0001`：对齐保留多峰互相关的全部合法候选，不唯一时由人工裁定。
- `R-RAW-0001`：导入不做不可逆清洗；原始表示原样保存，无法转换的值留在原位置并附诊断。
